# Dotrift Agent Guide

## Project Overview
Dotrift is a Rust-based dotfile manager that maps files from a source directory to a target directory using declarative TOML configuration.

## Key Files
- `spec/*.md`: Specification of how the program should behave
- `Cargo.toml`: Rust package manifest
- `src/main.rs`: Application entrypoint

## Development Workflow
### Standard Rust Commands
- Build: `cargo build`
- Run: `cargo run -- [args]`
- Test: `cargo test`
- Check: `cargo check`
- Format: `cargo fmt`
- Clippy: `cargo clippy`
